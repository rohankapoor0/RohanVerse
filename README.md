# ROHANVERSE 🌌
### *The Multiverse of Rohan Kapoor — AI Engineer & System Architect*

A cinematic, ultra-high-performance cosmic observatory portfolio inspired by **Gargantua from Interstellar**, deep-space astrophysics, and Apple's minimalist design philosophy.

---

## 🌟 Key Features

- **Pure Black Canvas (`#000000`)**: Designed with zero generic dashboard aesthetic and zero neon cliches. Crisp, high-contrast typography and subtle luminous borders.
- **Ultra-Lightweight CSS Black Hole**: Searing white-hot photon boundary, warm-gold and amber thermal accretion horizon, and a submerged event horizon running at 60fps with zero WebGL/video lag.
- **Continuous Scroll Architecture**: Seamless single-page experience with real-time planetary scroll tracking and progress indicators.
- **Clark — Interactive Digital Twin**: Embedded inline on the homepage alongside Rohan Kapoor with 4 clickable FAQ bubbles and zero-latency contextual responses.
- **Planetary Section Navigation**:
  - **Earth (Electric Blue)** — Origin & Event Horizon
  - **Neptune (Violet)** — Academic Core, 9.14 CGPA, 2x Cyber Olympiad Gold Medals, and Technical Arsenal
  - **Mars (Warm Orange)** — Projects & Deployed Systems (Clark, StreamLens, WebsyApp, WithYou, MacroMitra, Hungr, DineWise)
  - **Saturn (Golden Amber)** — Industrial Battlegrounds (TCS, Sypha, KOPSCO Systems)
  - **Jupiter (Soft Pink)** — Research & Blueprints (Attention span dynamics, ISDC Drone Tech)
  - **Mercury (Silver)** — Direct Telemetry & Verified Channels

---

## 🚀 Tech Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS, Custom Layered Radial CSS Gradients
- **Typography**: Syne (Display), Inter (Body), JetBrains Mono (Telemetry)
- **Icons**: Lucide React

---

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
